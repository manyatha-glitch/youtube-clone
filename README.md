# YouTube Clone

A frontend clone of YouTube built using HTML5 and CSS3. The project recreates the core YouTube interface, including the navigation header, sidebar, video grid, thumbnails, and channel information. It demonstrates modern frontend layout techniques using Flexbox and CSS Grid.

## Live Demo

[View Live Demo](https://manyatha-glitch.github.io/youtube-clone/)


![YouTube Clone](screenshot.png)

## Features

- YouTube-inspired homepage interface
- Responsive video grid using CSS Grid
- Navigation header with search bar and action icons
- Sidebar with navigation options
- Video cards with thumbnails, titles, channel details, and metadata
- Clean project structure with organized assets
- Hover effects and interactive UI styling
- Pixel-accurate spacing and alignment

## Tech Stack

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
  
## Getting Started


2. Open the project folder.

3. Double-click `index.html` or open it with Live Server in VS Code.
